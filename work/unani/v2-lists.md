## 4. Schema misfit

- **Field 3 `construct_debate`: framing gap.** The codebook text says to "record any adjudication the report offers as its own", but the Leaf naming table gives field 3 only one leaf, `positions`. The report does offer an explicit adjudication ("reconstruction on a real foundation"; "most serious historians ... agree"), which has had to go into `positions.notes`. Proposed leaf: `construct_debate.report_adjudication` (value: the report's stated verdict, register historical-scholarship, marked as the report's stance and not consensus).
